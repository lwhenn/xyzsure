AI Compliance Help

How to run CAP checklist gap analysis, review evidence, and track remediation.

Overview

AI Compliance validates CAP checklist requirements using live LIMS data, indexed documents, and AI analysis. The main workflow is AI Gap Analysis — workbook-style gap assessment with evidence search and remediation tracking. Admin access is required.

Common Workflow
  1. Open AI Compliance → Gap Analysis (or start from the AI Compliance home tiles).
  2. Select the sheet/tab (if multiple) to load the CAP matrix.
  3. Check the requirement(s) you want to analyze.
  4. Choose an AI model from the drop-down.
  5. Click Run AI Gap Analysis to populate Status, Gap Analysis, Corrective Actions, AI Search Summary, and AI Search Evidence.
  6. Optionally ask follow-up questions on a requirement after the initial run.
  7. Enter or edit Remediation notes when corrective actions are complete — documented remediation can update requirement status when completion criteria are met.
  8. Use Show Gap Analysis Details to expand workbook columns (Status, Gap Analysis, Corrective Actions, Remediation).
  9. When prompted, choose whether to save results back to Google Sheets (export runs in the background).
  10. Revisit saved runs in Search Results or the Result Viewer.
Module pages
  • AI Gap Analysis: Workbook-style assessments with Status, Gap Analysis, Corrective Actions, Remediation, and evidence search
  • AI Search Results: Browse and manage saved compliance reports
  • Result Viewer: Inspect an individual requirement result with evidence excerpts
  • Document List: View indexed compliance documents used by AI search
AI capabilities
  • AI Search Summary: Audit-ready narrative of compliance evidence per requirement
  • AI Search Evidence: Ranked document excerpts supporting the summary
  • Gap Analysis: Identified gaps with regulatory context
  • Corrective Actions: Recommended remediation steps per requirement
  • Remediation: Track completed corrective actions in the workbook Remediation column
  • Follow-up questions: Ask clarifying questions after an initial Gap Analysis run
  • Smart Document Search: Finds relevant SOPs and validation documents
What is AI Gap Analysis?

The AI Gap Analysis page provides a site-specific CAP workbook review where you select individual requirements and run AI-powered gap assessment with document search. Use it when you need evidence, gap narrative, corrective actions, and remediation tracking for a subset of checklist items (for example, GEN.* items for a specific instrument or workflow).

  • Matrix-driven: Reads your CAP Custom Checklist Matrix (CSV or Google Sheet) and exposes requirement rows for selection.
  • Per-requirement AI context: The AI receives requirement metadata (including Subject and Policy/Procedure) plus Evidence/Notes to build audit-ready recommendations.
  • Save back to sheet: After analysis you may save Status, Gap Analysis, Corrective Actions, Remediation, and AI Search fields back to the Google Sheet. Export is non-blocking.
Important notes and troubleshooting
  • Subject & Policy/Procedure: Included in the AI prompt. In some setups Policy/Procedure is maintained in the canonical CAP Google Sheet (CAP_SHEET_ID) rather than the local matrix — Gap Analysis reads it from the CAP sheet when available.
  • UI row updates: Selected requirement codes are matched to table rows to update Status, Gap Analysis, Corrective Actions, AI Search Summary, and AI Search Evidence. If values do not update, inspect the JSON response in Developer Tools → Network.
  • Saving to Google Sheets: Requires write access for the app’s Google credentials. Failures are shown in the UI; reports can still be stored locally. Sheet export is non-blocking.
  • Permissions & API keys: AI features need a provider API key; Google integrations need valid credentials. Check Admin Panel → Settings if you see authentication errors.
CAP Custom Checklist Matrix AI Input

These matrix fields drive evaluations and enrich AI prompts:

  • Requirement ID / Requirement: Match selected codes to matrix rows and build keyword tokens for document search.
  • Type: Marks a requirement as Automated, Partial, Manual, or N/A. An empty Status is treated as Not Applicable.
  • Evidence Source and Notes: Shown in the matrix UI and included in the AI evidence payload.
  • Section: Used for grouping and display; helpful context but not required for AI prompts.
Tip: Run gap analysis regularly before CAP inspections. The system queries live LIMS data and Document Control records to identify gaps; AI provides actionable recommendations for your findings.
Understanding results
  • Findings: What the system discovered during validation
  • Evidence: Supporting data from LIMS / Document Control
  • AI Search Summary: Audit-ready narrative summary of compliance evidence
  • AI Search Evidence: Ranked document excerpts supporting the summary
  • Gap Analysis / Corrective Actions / Remediation: Workbook fields for tracking gaps and completed remediation
AI setup (optional)

To enable AI features, add a provider API key to your .env file.

Without an API key, matrix browsing and non-AI workflows still work, but Gap Analysis and document search require a configured model.
